Night Ledger is a top-down stealth game: slip through three dark halls of a night facility, lift every ledger while guards sweep their vision cones, and reach the green exit door unseen. Shadow hides you, lamplight betrays you, and a spotted guard gives chase — break line of sight to cool the hunt down.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD/arrows to move, SHIFT to run (loud), C to sneak (silent), P to pause, M to mute.
